## Information Required

For each building/facility listed below, the following information must be provided:

### 1. Building Drawings
- Floor plans with room layout and elevations
- Drawings showing noted buildings (1 to 8)
- Drawings showing room outlays with equipment (equipment enclosures) deployed
- See examples of floor plans (to be provided)

### 2. List of Equipment
- New equipment to be introduced within the buildings (1 to 8) noted under Project DP2-4 only
- Equipment (apparatus) details, for example: industrial switch
- Brand and model (leverancier / type), for example: Ruggedcom, RS900NC
- See example below (to be provided)

### 3. Equipment Specifications
- EMC specifications for the equipment listed
- Allow for the EMC check-list to be completed in accordance to relevant standards
- Equipment datasheets and/or specifications will assist

## Instructions for Design Teams

1. **Identify** which building(s) your discipline is responsible for
2. **Navigate** to the appropriate building folder
3. **Upload** your documents to the correct sub-folder:
   - CAD drawings → `1-Building-Drawings/`
   - Equipment lists/tables → `2-List-of-Equipment/`
   - Datasheets/specs → `3-Equipment-Specifications/`
4. **Read** the README.txt in each sub-folder for specific requirements
5. **Complete** the upload before the deadline
